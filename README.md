# MinimalTab

> **A minimalist, productivity-first browser homepage designed to help you focus, organize, and start every browsing session with purpose.**

MinimalTab is a modern browser homepage inspired by **Notion**, **Arc Browser**, **Raycast**, **Linear**, and **Apple's Human Interface Guidelines**. It replaces the traditional new tab experience with a clean, distraction-free workspace that combines universal search, productivity tools, quick access, notes, and customization into one elegant interface.

Built with performance, simplicity, and usability in mind, MinimalTab is designed for students, developers, professionals, and anyone who wants a faster and more organized browsing experience.

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/minimaltab.git
```

## Navigate to the Project

```bash
cd minimaltab
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

# 🌐 Deploy Your Own Version (Netlify)

You can deploy your own copy of MinimalTab in just a few minutes.

### 1. Fork or Clone this Repository

Create your own copy of the project on GitHub.

### 2. Create a Netlify Account

Visit:

https://www.netlify.com/

Sign in using your GitHub account.

### 3. Import Your Repository

- Click **Add New Site**
- Choose **Import Existing Project**
- Select **GitHub**
- Choose your MinimalTab repository

### 4. Build Settings

Build Command

```bash
npm run build
```

Publish Directory

```text
dist
```

### 5. Deploy

Click **Deploy Site**.

Netlify will automatically build and host your project.

You'll receive a free deployment URL similar to:

```
https://your-project.netlify.app
```

### 6. Automatic Deployments

Every time you push changes to GitHub:

```bash
git add .
git commit -m "Update MinimalTab"
git push origin main
```

Netlify will automatically rebuild and deploy the latest version.
